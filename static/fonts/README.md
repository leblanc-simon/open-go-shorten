# Fonts

Latin subsets of the following fonts, served locally (no third-party request):

* IBM Plex Sans (variable, 400 to 600) and IBM Plex Mono (500): https://github.com/IBM/plex
* Space Grotesk (600): https://github.com/floriankarsten/space-grotesk

They are licensed under the SIL Open Font License 1.1: https://openfontlicense.org
